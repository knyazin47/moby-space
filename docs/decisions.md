# Технические решения

Moby Space создан командой в рамках Space Hackathon с МТБанком.
Ниже — действующие решения прототипа.

## Два самостоятельных режима

Локальная реплика сохраняет автономные экраны и fixtures. Семейный режим
явно включается через `MOBY_API_URL` и использует backend. Ошибка подключения
не переключает пользователя в другую модель данных. Это позволяет отдельно
проверять UI и общий семейный сценарий; обе ветви требуют регрессий.

## Flutter, Go и SQLite

Flutter обеспечивает общие Android/iOS-исходники. Go/SQLite хранит один
синтетический семейный стенд с нулём детей при первом запуске. Горизонтальное
масштабирование и банковская многопользовательская модель не заявляются.

## Общая доменная логика

Native gRPC/protobuf — транспорт нового клиента; REST/SSE сохраняет
совместимость. Общие application-методы проверяют role/scope, идемпотентность,
резервирование и состояние независимо от транспорта.

## Денежные правила

Суммы — integer minor units. Доступный остаток, резерв, деньги цели и ожидаемая
компенсация различаются. При недостатке регулярных выплат решение принимает
взрослый; скрытого приоритета по порядку детей нет. Отмена не изымает
выплаченную награду. Уроки не выдают финансовые права.

## Ресурсы и упаковка

Оба режима светлые, темы изолированы. Графика без подтверждённых условий
заменяется стандартными Material Icons и собственными иллюстрациями с сохранением
маршрутов и сценариев обоих режимов. Лицензия своего кода не распространяется
автоматически на банковскую графику. [Реестр ресурсов](../tools/assets/README.md)
отделён от исторических дизайн-материалов. Публичный API не является
обязательной зависимостью сборки локальной реплики.
