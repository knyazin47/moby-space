# Архитектура Moby Space

Командный прототип Space Hackathon с МТБанком: Flutter Android/iOS, Go и SQLite.
Личности и деньги синтетические; банковские системы, SMS/KYC и выпуск карт
не подключены.

## Два режима

Без `MOBY_API_URL` открывается локальная реплика. `DemoBankRepository` и
локальный `FamilyStore` меняют данные в памяти; перезапуск восстанавливает
демосценарий. Общей семьи между устройствами в этом режиме нет.

С `MOBY_API_URL` включается семейный вход. Go/SQLite хранит профили, права,
сессии, цели, поручения, выплаты и историю. Flutter использует типизированный
native gRPC/HTTP2. REST/SSE сохраняет совместимость под теми же application
методами; это не независимый backend.

| Путь | Ответственность |
| --- | --- |
| `frontend/lib/app/` | Запуск, маршруты и жизненный цикл сессии |
| `frontend/lib/core/config/` | Типизированный контент и demo defaults |
| `frontend/lib/core/theme/`, `core/ui/` | Темы и общие компоненты |
| `frontend/lib/features/` | Экраны обоих режимов |
| `frontend/lib/data/family/` | Локальная семейная модель |
| `frontend/lib/data/server/` | gRPC, session vault, outbox и generated-клиент |
| `backend/internal/api/` | Application/domain, SQLite и REST/SSE |
| `backend/internal/grpcapi/` | RPC, protobuf mapping и admission |
| `proto/` | Версионированные wire-контракты |
| `tools/assets/` | Происхождение, хеши и лицензии ресурсов |
| `deploy/` | Переносимый пример самостоятельного запуска |

## Транзакции и доступ

Оба транспорта вызывают общие методы под синхронизацией. Роль, принадлежность
ребёнка, состояние и денежные ограничения проверяются до записи. Суммы —
integer minor units BYN. Идемпотентный ключ связан с содержимым команды;
повтор не создаёт вторую выплату.

Adult bootstrap — секрет владельца одного synthetic семейного стенда, не
многопользовательская банковская авторизация. Sessions хранятся в OS
Keystore/Keychain. Logout отзывает сеанс и сохраняет семью. Child snapshot
не содержит adult wallet и соседних профилей.

QR содержит короткоживущий запрос, а не session token. Взрослый подтверждает
конкретного ребёнка. Истёкшие запросы освобождают очередь. REST SSE и gRPC Watch
имеют ограничения подписок, повторно проверяют сеанс и освобождают ресурсы
при отключении.

## Повтор и обновления

WatchSnapshots передаёт разрешённый snapshot, объединяя промежуточные revisions.
Сетевой сбой после commit не равен отказу: клиент повторяет исходный intent
с прежним ключом. Outbox связан с сеансом и endpoint; смена пользователя
не переносит чужую команду.

Локальная реплика не является fallback семейного режима. Synthetic verification
не подтверждает юридические полномочия. OS push и автоматические возрастные
переходы не реализованы.
