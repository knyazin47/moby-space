# Навигация

Moby Space — прототип Space Hackathon с МТБанком с двумя режимами.

Без `MOBY_API_URL` работают локальные главная, продукты, чат, дополнительные
страницы и платёжные формы с synthetic fixtures. Данные не синхронизируются.

С API приложение показывает выбор роли и вход. У взрослого самостоятельная
вкладка «Детям». Первое знакомство сохраняется на сервере; отсутствие детей
или возврат не сбрасывают его. Доступны создание/подключение профиля, обзор,
деньги, дела, цели, обучение и правила. Профиль открывается через аватар.

У ребёнка собственные Moby/Деньги/Дела/Цели/Учиться. Сеанс определяет child scope.
Inbox открывает разрешённый раздел и не исполняет денежное решение прочтением.
Формы показывают остаток; «Максимум» заполняет поле без исполнения перевода.
Нижняя панель не должна перекрывать финальное действие, включая narrow/large text.

Маршруты: `frontend/lib/app/router.dart`; проверки:
`frontend/test/router_test.dart`, `frontend/test/design/space_preview_test.dart`.
