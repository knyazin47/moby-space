# Продукт Moby Space

Командный семейный прототип Space Hackathon с МТБанком. Сохранены локальная
реплика интерфейса и семейный режим. Деньги и личности синтетические.

- [Сценарии и денежные правила](family-space-v2.md).
- [Навигация](navigation.md).
- [Inbox и неподключённый OS-контракт](notifications.md).
- [Границы данных и доступа](safety-boundaries.md).
- [Источники изменяемого контента](../ADMIN_CONFIGURABILITY.md).

Рабочие семейные сценарии: профили детей, QR-подключение, политики, переводы
и решения по покупкам, цели, задания, поручения с компенсацией, регулярные
выплаты, уроки и история. Локальная реплика хранит отдельный сценарий в памяти.

Экраны не означают наличие настоящего KYC, эмиссии, договора, страховки,
партнёрских услуг или автоматических возрастных переходов.
